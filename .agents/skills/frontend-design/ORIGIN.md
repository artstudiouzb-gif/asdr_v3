(LICENSE.txt рядом). Поставлен `npx skills add`, отпечаток — в `skills-lock.json`.
Взято без правок, чтобы обновление сводилось к замене файла.

Скилл написан для нового интерфейса «с чистого листа» — у нас живой госсайт с
настройками оформления в админке. Правила проекта важнее этого файла.
Расхождения, о которых договорено:

- **Выделение слова в заголовке** скилл называет первым признаком
  сгенерированной страницы. У нас это функция (`*слово*`, `TitleMarkup`,
  настройка «Дизайна» `title_mark`) — редактор ставит выделение сам, по месту.
  Скилл здесь — довод против выделения по умолчанию, а не против функции.
- **Палитра и шрифты** не подбираются «под бриф»: акцент и основной цвет
  приходят из админки (`--color-accent`, `--color-primary`), шрифты — каталог
  `DesignSettings` с обязательной кириллицей (Ғғ Ққ Ҳҳ).
- **Шкалы**: кегль — только `--step-*`, точки перелома — общая шкала,
  скругления и тени — роли `tokens.css`. «Своя шкала под проект» скилла у нас
  уже есть и числами по месту не заменяется.
- **Смелость в одном месте** — принимается как правило, но решение, какой
  элемент главный, принимает владелец (главная — эталонная страница,
  DESIGN_PLAN 3.2).
- **Спор решает замер** (CLAUDE.md, «Два дизайнера»): «выглядит шаблонно» без
  измерения — не довод. Признаки из скилла меряются, см. DESIGN_PLAN,
  очередь 4.
