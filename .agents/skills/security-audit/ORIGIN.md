# Как взят

Без правок — обновление сводится к повторному запуску той же команды. Всё, что
расходится с проектом, описано здесь и решается в пользу проекта.

# Расхождения с проектом

- **Скилл по умолчанию только советует.** Полный цикл аудита с файлами отчётов
  он запускает лишь по явной просьбе; в этом проекте так и оставляем — отчёты
  в репозиторий не кладём.
- **Проверка — не замена CI.** Свои сторожа у проекта уже есть: PHPStan
  (уровень 7, блокирующий), `composer audit`, CodeQL для JS и собственный
  набор тестов. Находки скилла — это повод к правке кода, а не второй эталон:
  в бюджеты качества (`tests/budgets.php`) они не заводятся.
- **Публичная часть в сеть не ходит** (тест 110), произвольный код доступен
  только супер-админу, а CSP работает через nonce. Рекомендация, которая
  предлагает встроить сторонний скрипт, внешний виджет или запрос из рендера
  публичной страницы, в этом проекте не принимается — это разобранные решения,
  а не пробел.
- **В релизный архив скилл не попадает**: `/.agents export-ignore` в
  `.gitattributes`, как и `/.claude`.
