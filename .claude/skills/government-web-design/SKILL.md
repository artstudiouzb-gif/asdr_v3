# Проверка интерфейса

Договорённости о стиле, токенах, коммитах и PR — в `CLAUDE.md`, здесь они не
повторяются. Этот файл только о том, как проверять сделанное: правки ломаются
не там, где их видно, а там, где никто не смотрел.

## Обязательные ширины

**1440, 1280, 1024, 768, 390, 320.** Именно 320: до неё доходят старые телефоны
и режим увеличения, и ровно на ней ломается то, что на 390 ещё помещается.
Проверять и ширины по обе стороны от заметных брейкпоинтов.

На каждой ширине: нет горизонтального скролла, нет обрезанного текста и
элементов, ничего не перекрывает друг друга, цели нажатия не мельче ~24px,
картинки держат пропорции, порядок содержимого осмыслен.

## Состояния, а не только «как обычно»

Проверять то, что редактор и посетитель увидят на самом деле:

- пусто, одна запись, очень много записей;
- очень длинный заголовок и заголовок из одного слова;
- нет картинки, картинка вертикальная, картинка тяжёлая;
- ошибка формы с сохранением введённого;
- наведение, фокус с клавиатуры, активное, раскрытое, выключенное;
- шапка прозрачная и обычная, приклеенная и в покое;
- тёмная тема и «Настройки отображения» (контраст, крупный шрифт, без анимаций);
- RU и UZ, включая узбекскую кириллицу.

Демо-контент не представляет боевой: на нём всё всегда помещается.

## Контраст

WCAG AA: 4.5:1 для обычного текста, 3:1 для крупного (24px, либо 18.66px
полужирный) и для границ элементов управления. Мерить в каждом состоянии и в
обеих темах, а не только по умолчанию.

Заливка бренд-акцентом — отдельный случай: белый текст читается не на всяком
акценте. Цвет текста берётся из `--on-accent` (считается на сервере из
акцента), для текста по светлому фону — `--gov-teal-text`. Сырой
`--color-accent` в тексте — ошибка.

## Клавиатура и семантика

- первый Tab даёт видимую ссылку «Перейти к содержимому»;
- фокус виден на каждом интерактивном элементе;
- меню: `aria-expanded` переключается, Escape закрывает, фокус возвращается
  на кнопку, которая открывала;
- один `h1` на страницу, уровни заголовков без скачков;
- ссылка ведёт, кнопка действует; интерактив не вкладывается в интерактив;
- дублей `id` нет; у картинок есть `alt` (пустой у декоративных).

## RU и UZ

Каждый язык — самостоятельный контент, а не суффикс. Проверять, что на
странице нет чужого языка: строка, забытая в словаре, выходит по-русски на
узбекской версии и наоборот. Ключ словаря — всегда русская фраза.

Сохранять `oʻ`, `gʻ` с правильным апострофом. Переполнение меню проверять на
обоих языках: узбекские подписи длиннее.

## Как мерить, чтобы не выдумать

Ошибки измерения дороже ненайденных багов — по ним принимают решения. Что
подводило на этом проекте:

- **полупрозрачный фон.** `rgba()` и `color-mix()` нельзя считать сплошным
  цветом: нужно наложить слой на фон родителя. Иначе контраст выходит
  фантастическим;
- **текст поверх фото.** Там фон — изображение, цветом контраст не считается.
  Такие места смотреть глазами, а не формулой;
- **CSS-переход.** Замер сразу после `focus()` или клика попадает в середину
  анимации: outline «0px» может означать, что кольцо ещё не доросло. Дать
  переходу доиграть;
- **скрытые копии.** Off-canvas меню и модалки отрисованы всегда: их светлый
  текст на светлом фоне — не дефект, а стиль для раскрытого состояния;
- **`.focus()` из скрипта** не то же, что Tab: `:focus-visible` может не
  примениться. Проверять настоящими нажатиями;
- **скриншот без прокрутки** не грузит ленивые картинки — «чёрные карточки»
  на снимке могут быть артефактом, а не вёрсткой.

Прежде чем сообщить о дефекте — воспроизвести его вторым способом. Прежде чем
чинить — убедиться, что чинить есть что: правило, снятое из таблицы стилей
прямо в браузере, показывает, как было до правки.

## Прогон перед сдачей

```bash
TEST_DB_HOST=127.0.0.1 TEST_DB_DATABASE=artstudio_test TEST_DB_USERNAME=root TEST_DB_PASSWORD= php tests/run.php
php scripts/smoke.php http://127.0.0.1:8000 --admin admin:ПАРОЛЬ --totp СЕКРЕТ
npm run build:assets && npm run check:assets
```

Верификация соразмерна правке: мелкая правка CSS не требует полного обхода, но
требует тех ширин, которых касается.

Не писать «проверено», «работает», «тесты зелёные», пока команда не выполнена и
не показала это. Если проверить не удалось — сказать, что именно осталось
непроверенным, и почему.
