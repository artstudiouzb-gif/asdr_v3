# Скрытый вход в административную панель

Функция включается только после настройки `ADMIN_ENTRY_PATH`. Пока переменная
пустая, существующие установки продолжают использовать `/admin/login` без
изменений и не рискуют потерять доступ после обновления.

## Настройка

Сгенерируйте непредсказуемый одноуровневый путь длиной не менее 16 символов:

```bash
php -r "echo '/control-' . bin2hex(random_bytes(12)), PHP_EOL;"
```

Добавьте полученное значение в переменные окружения хостинга:

```dotenv
ADMIN_ENTRY_PATH=/control-REPLACE_WITH_RANDOM_VALUE
ADMIN_ENTRY_TTL=1800
```

Подпись временного cookie по умолчанию использует `APP_ENCRYPTION_KEY`.
Отдельный ключ можно задать через `ADMIN_ENTRY_KEY`:

```bash
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
```

```dotenv
ADMIN_ENTRY_KEY=REPLACE_WITH_64_HEX_CHARACTERS
```

После включения вход выполняется по адресу:

```text
https://example.com/control-REPLACE_WITH_RANDOM_VALUE
```

Прямые неавторизованные запросы к `/admin`, `/admin/login`, `/admin/forgot`,
`/admin/reset/*` и другим маршрутам панели получают обычный ответ `404` без
редиректа на форму входа.

## IP allowlist

Для статического офисного/VPN-адреса можно дополнительно закрыть весь `/admin`
и секретный gateway по CIDR:

```dotenv
ADMIN_ENTRY_ALLOWED_CIDRS=203.0.113.24/32,2001:db8:1234::/48
```

Пустое значение разрешает доступ с любого IP. Не включайте allowlist для
динамического адреса без резервного способа изменить конфигурацию на сервере.

## Проверка

Без gateway-cookie прямой адрес должен вернуть `404`:

```bash
curl -I https://example.com/admin/login
```

Секретный путь должен вернуть `302`, установить `Secure; HttpOnly;
SameSite=Strict` cookie и перенаправить на `/admin/login`:

```bash
curl -i https://example.com/control-REPLACE_WITH_RANDOM_VALUE
```

Ссылки восстановления пароля автоматически проходят через секретный gateway,
поэтому они продолжают работать в другом браузере и после истечения старого
пропуска.

## Ротация и аварийное отключение

Если секретный путь попал в журнал, переписку или скриншот, замените значение
`ADMIN_ENTRY_PATH`. Старый адрес сразу перестанет работать.

Для аварийного возврата к стандартному входу удалите или очистите
`ADMIN_ENTRY_PATH`. Это отключает только дополнительный gateway и не меняет
пароли, 2FA, сессии или RBAC.

Скрытый путь уменьшает шум сканеров, но не заменяет сильный пароль, 2FA,
rate limiting, обновления и ограничение доступа к origin-серверу.
