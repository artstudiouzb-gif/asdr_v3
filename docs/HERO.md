# Модуль обложек

Обложка — переиспользуемая секция с общим оформлением и упорядоченными
слайдами. Раздел `/admin/heroes` управляет содержимым, блок страницы выбирает
обложку по `hero_id`. Таблицы и формат настроек не меняются.

## Разделение ответственности

| Компонент | Задача |
|---|---|
| `HeroSettings`, `HeroPresets` | Проверенные настройки оформления и стартовые пресеты |
| `HeroSlideData` | Содержимое кадра, ссылки, медиа и переопределения |
| `HeroRenderer` | Композиция кадра, типографика, контраст и scoped CSS |
| `HeroMediaRenderer` | Адаптивные постеры, источники видео, YouTube facade |
| `HeroNavigation` | Навигация и управление движением, включая одиночное видео |
| `blocks/hero.js` | Состояние показа, медиасессии и жизненный цикл экземпляра |

У каждого экземпляра независимы намерение посетителя, наведение, видимость
на странице и состояние вкладки. Обновление одного признака не снимает
остальные причины паузы. Это заменяет общий флаг `suspended` и таймер
автоматического возобновления после взаимодействия.

## Поведение

- Наведение временно приостанавливает смену слайдов. Фокус с клавиатуры и
  ручное переключение останавливают показ до команды «Продолжить показ».
- На телефоне автопрокрутка изначально приостановлена, но её можно запустить.
- Системное уменьшение движения и настройка доступности выключают видео,
  автоматическую смену и анимации. Возвращение обычного режима само по себе
  не отменяет паузу. Save-Data исключает загрузку фонового видео.
- Вне экрана и в скрытой вкладке таймеры и видео останавливаются, в том числе
  у одиночной видеообложки. Возвращение учитывает сохранённую ручную паузу.
- Скрытые слайды получают `inert` и `aria-hidden` при инициализации JS.
  Ручное переключение объявляется через отдельную live-область; автоматическое
  переключение не засоряет озвучивание.
- До загрузки JS слайды доступны нативной горизонтальной прокруткой. Их
  содержимое не скрыто от вспомогательных технологий серверной разметкой.
- Первая картинка получает высокий приоритет загрузки; остальные — lazy.
  У видео до активации вообще нет `src`, включая первый кадр. Источник для
  телефона выбирается перед первой загрузкой.
- Кадр-замена остаётся под видео. Отказ `play()` и запоздалые промисы
  из предыдущей медиасессии не могут остановить новую сессию.
- YouTube показывается только после сообщения PLAYING от ожидаемого iframe
  и origin. Нет подтверждения за четыре секунды — остаётся постер. Уход со
  слайда отменяет его обработчики и таймаут, а не только удаляет iframe.

## Жизненный цикл

Обычная страница инициализируется автоматически. При добавлении новых обложек
в динамический предпросмотр отправить `asdr:hero-init` на `document`.
Повторная инициализация уже подключённого экземпляра ничего не делает.
Перед удалением отправить `asdr:hero-destroy` на его `[data-hero]`: обработчики,
наблюдатель видимости, таймеры переходов и медиасессии будут освобождены.

## Проверки

`tests/browser/hero-runtime.spec.js` проверяет реальный JS и CSS обложек:
конфликтующие паузы, ручной запуск, длительность кадра, быстрые переходы,
мобильный режим, reduced motion, одиночное видео, ошибки и запоздалые
промисы, YouTube, несколько экземпляров, освобождение ресурсов и fallback.
Сетевые плееры заменяются управляемыми имитациями; эти проверки не измеряют
качество декодирования реальных роликов или доступность YouTube.

`tests/cases/hero_module_test.php` проверяет контракт серверной разметки.
Другие `*hero*test.php` проверяют нормализацию, оформление, переводы и расписание.

```bash
php tests/run.php
npx playwright test tests/browser/hero-runtime.spec.js
npm run build:assets
npm run check:assets
```

## Основания решений

- [WAI-ARIA Carousel Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/):
  управление вращением до контента; фокус останавливает смену до явного запуска.
- [web.dev: Optimize LCP](https://web.dev/articles/optimize-lcp):
  LCP-картинка не должна загружаться лениво.
- [web.dev: Fetch Priority](https://web.dev/articles/fetch-priority):
  высокий приоритет первого изображения, а не всех кадров карусели.
- [MDN: Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API):
  прекращение фоновой работы скрытой страницы.
- [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference):
  готовность плеера и состояние PLAYING — разные события. Проверка сообщений
  facade использует существующий обмен `postMessage`, без загрузки внешнего SDK.

## Редактор настроек

Варианты оформления, цвета и переходы названы по результату, без английских
технических терминов. Своя высота, даты публикации, цвета наложения, параметры
кнопок и видеоссылки появляются только в соответствующем режиме. Скрытые
значения остаются в форме и не теряются при переключении. Сводки свёрнутых
групп обновляются при вводе. Ошибочные границы расписания проверяются в форме.

Для отдельного мобильного MP4 есть поле адреса. Явный выбор «Только цвет
обложки» выключает ранее выбранные медиа; переключение на фотографию не
подставляет старую заставку видео. Умолчания импорта без media_type сохранены.
Поведение редактора проверяется в `tests/browser/hero-editor.spec.js`.
