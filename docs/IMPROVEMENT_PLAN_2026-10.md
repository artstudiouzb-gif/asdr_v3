# План улучшений по итогам ревизии (октябрь 2026)

Сводный план по шести независимым разборам: безопасность, качество кода,
производительность, вёрстка и доступность, композиция и фирменный слой,
функциональность. Разбор статический (по коду, HEAD `d69515d`), сайт не
запускался. Находки, помеченные **[подтв.]**, сверены с кодом ведущим сеансом;
остальные — по отчётам агентов, их надо подтвердить перед правкой (тестом или
замером). Уже записанное в ROADMAP_V4/V5, DESIGN_PLAN и PERFORMANCE_PLAN здесь
не повторяется, кроме случаев, где нашёлся дефект.

Принцип порядка: сначала то, что ломается молча (дыры, неверные данные,
слепые сторожа), потом то, что ускоряет каждую страницу, потом функции и вид.
Каждая очередь — отдельные PR небольшого размера, у каждого свой тест.

### 1.1. Браузерный кэш не сбрасывается кнопкой «Сброс кэша» **[подтв.]**

Кнопка чистит файловый кэш, Cloudflare и OPcache, но то, что уже лежит в
браузере, сервер стереть не может:

- **HTML** уходит с `max-age=perf_public_cache_ttl` (60 с по умолчанию, до
  3600; `PublicResponseCache.php:107,151-157`) — в течение срока браузер не
  спрашивает сервер. Решение: браузеру `max-age=0, must-revalidate` + ETag
  (304 в ~300 байт), `s-maxage` для CDN оставить.
- **Браузер самого админа**: ответ `clearCache` дополнить
  `Clear-Site-Data: "cache"` (домен общий с сайтом, нужен HTTPS).
- **Файлы**: `public/.htaccess:51-53` ставит `max-age=31536000, immutable`
  всем картинкам и SVG, включая `/uploads`, хотя `?v=` получают только адреса
  из `Asset::url()`. Перезаписанный по тому же адресу файл (эмблема, логотип,
  пересобранные варианты, перекадрирование) браузер не перезапросит год, даже
  по обычному обновлению. Решение: `immutable` только при `v=` в запросе
  (`<If "%{QUERY_STRING} =~ /(^|&)v=/">`), остальным — `max-age=86400` с
  перепроверкой; либо `?v=mtime` к медиа при выводе.

## Очередь 5. Безопасность: системные меры

1. **Доступ — атрибутом маршрута, а не вызовом в действии.** Сейчас
   `requireLogin`/`requireSuperAdmin`/`RbacGuard::can` вызываются вручную в ~300
   методах; новый `/admin`-маршрут без вызова открыт анонимам. Таблица
   маршрутов с `public|login|super|permission:x`, проверка в роутере, тест «у
   каждого `/admin/*` задан доступ» — тот же приём, что CSRF в роутере (тест 413).
2. **Нормализация блока по роли в `Block::create/update`**, а не точечными
   `if (!isSuperAdmin)`: сверить `SnippetController::insert/applyPreset`,
   `PageTranslationFile::import`, `Page::duplicate`, `copyLanguageBlocks` —
   не протаскивают ли они `custom_css`/`html` супер-админа в обход.
3. **Единый выходной фильтр rich-text** (см. SEC-1) + тест-обход полей с HTML.
4. Мелкие: сигнатура файла для svg/woff/аудио в `Uploader`; нормализация
   IPv4-mapped/NAT64 в `UrlGuard`; запрет `scripts/`, `vendor/`,
   `node_modules/`, `*.json|neon|lock|mjs` в корневом `.htaccess`; одноразовый
   токен установщика; ротация CSRF-токена после входа.
5. **Второй круг аудита** — не просмотрены: Updater, SiteMigration,
   BackupRestore, LegacyDocumentImporter, Xlsx-импорт, PageTemplateFile, портал
   `/repo`, SecretBox, журналы, вебхуки, Instagram/YouTube/LinkChecker, push,
